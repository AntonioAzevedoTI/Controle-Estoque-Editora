# Sistema de Controle Estoque Editora

## 1. Introdução
Este projeto consiste no desenvolvimento de uma solução com o Microsoft Excel para controle de estoque em uma editora.<br>
O sistema foi criado para centralizar informações sobre os títulos publicados, registrar movimentações de estoque e disponibilizar consultas rápidas de saldo para apoio aos processos operacionais e comerciais.

## 2. Problema
A editora possuía diversos títulos em estoque, porém o controle era realizado de forma descentralizada e no formato de papel.<br>
As principais dificuldades observadas eram:<br>
•	Dificuldade para localizar rapidamente a disponibilidade de livros.<br>
•	Ausência de um controle consolidado de entradas e saídas.<br>
•	Falta de rastreabilidade das movimentações.<br>
•	Dificuldade para gerar relatórios de Direitos Autorais.<br>
•	Demora no atendimento aos vendedores.<br>

## 3. Objetivo
Desenvolver uma solução em Excel capaz de centralizar o cadastro de títulos, controlar a movimentação de estoque e fornecer consulta imediata do saldo atualizado.

## 4. Solução Desenvolvida
A solução desenvolvida com o Excel foi estruturada nas seguintes abas:<br>
•	Cadastro.<br>
•	Movimentação.<br>
•	Consulta.<br>
•	Dados de Apoio.<br>
O sistema utiliza o ISBN como chave principal das informações e cálculo automático dos saldos de estoque.

## 6. Resultados Obtidos
A implementação da solução proporcionou mudanças significativas.<br>
Antes:<br>
•	Controle realizado em papel.<br>
•	Informações descentralizadas.<br>
•	Dificuldade para identificar disponibilidade real dos títulos.<br>
•	Ausência de histórico consolidado.<br>
Depois:<br>
•	Redução do tempo de consulta de disponibilidade de títulos.<br>
•	Centralização das informações de estoque.<br>
•	Maior confiabilidade das movimentações registradas.<br>
•	Apoio à tomada de decisão comercial.<br>
•	Base estruturada para apuração de direitos autorais.<br>
